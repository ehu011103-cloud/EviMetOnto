# Released artifacts

This directory contains only legally redistributable derived artifacts. It does not contain source PDFs, DOC_A full text, raw LLM responses, API logs, or verbatim evidence spans.

- `doc_a_manifest_5723.csv`: source metadata and checksums for the 5,723 structured input records; no text fields are released.
- `gold_v8_relation_labels.csv`: canonical hierarchy and non-hierarchical relation keys with final Gold decisions; evidence text and reviewer notes are excluded.
- `table_3_endpoint_compatibility_results_final.csv`: paper-facing Table 3 result rows under the fixed endpoint-compatibility protocol.
- `full_4d_extraction_summary.json` and `full_4d_validation_summary.json`: aggregate construction and validation statistics.
- `release_artifact_summary.json`: record counts and explicit exclusion list.
